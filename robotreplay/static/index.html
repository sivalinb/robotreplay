What a release still needs

Whole-session held-out video, mentor labels, event precision/recall, timestamp error, useful abstention, false-refusal checks, and student/mentor feedback. Synthetic policy tests do not establish real-world vision accuracy or learning impact.

Defense in depth

Make boundaries visible.

Exercise the actual policy checker; authentication, team scoping, and output validation are enforced independently.

Enforced boundaries

  • Hashed passwords and session tokens; HttpOnly cookies; CSRF and origin checks.
  • Team-scoped video, observations, retrieval, reports, and traces.
  • Permission records, upload limits, bounded video worker, and deletion of source plus derivatives.
  • Read-only graph with no shell, robot control, or bulk-export tool.
  • Strict model output: approved question IDs and existing evidence IDs.
  • Deadlines, no automatic provider retry, conservative budget reservations.

NeMo Guardrails is an optional extra input rail. Keyword rules are a limited baseline; semantic jailbreak resistance needs broader evaluation. Shared hosting also needs TLS and deployment review.
